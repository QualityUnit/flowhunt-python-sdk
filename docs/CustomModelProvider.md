# CustomModelProvider

The provider variant the user picked when adding a custom model.  All current providers speak the OpenAI-compatible HTTP shape at runtime (so ``compatibility`` stays ``OPENAI`` for every value here). This field exists purely so the UI can re-open the same provider-specific edit form and tailor its instructions and model-id input.

## Enum

* `OPENAI_COMPATIBLE` (value: `'openai_compatible'`)

* `OLLAMA` (value: `'ollama'`)

* `NVIDIA` (value: `'nvidia'`)
